# Space Invaders in 10 lines of code

All .do files are untokenized (text) BASIC.

> [!WARNING]
> This is a work in progress and none of the versions are fully functional.

## vad0

12 aliens, graphical tank, shoots stars, does not stop when hits an alien

## vad1

8 aliens, text tank, shoots stars, does not stop when hits an alien

some kind of bug that it sometimes sends one alien down, then it crashes

## vad2

10 aliens, text tank, shoots stars, registers hits and score, bug with down missiles

very jumpy

## vad3

similar to vad2

10 aliens, text tank, shoots stars, registers hits and score

bug when aliens are hit

no down missiles

smoother than vad2

(best option)

## vad4

9 aliens, all text

keeps score, but you can hardly see the up or down missiles
